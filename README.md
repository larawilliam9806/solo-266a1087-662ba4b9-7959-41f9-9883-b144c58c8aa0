# 电量日核算（Flask + SQLite）

电网数据员上传晚到的电表累计读数与换表记录，系统按计量点把相邻读数连成区间，
自动算出可核算的逐日用电量，并标记换表造成的缺口区间；
对机械表盘计量点可配置归零电量与最大功率，自动推算归零次数并处理待核区间。

## 业务规则

- **读数 CSV**（表头 `point,ts,value`）：计量点、UTC 时刻（ISO 8601，须带 `Z` 或 `+00:00`）、
  非负十进制千瓦时累计读数。
- **换表 CSV**（表头 `point,ts`）：计量点、UTC 换表时刻。
- **归零配置**（网页 `GET/POST /config`）：为计量点设置/修改归零电量 `R`（kWh）与最大功率 `P`（kW），
  两项均为正数。**未配置的计量点沿用原规则**（增量 = 后次 − 前次，倒退即拒）。
- **幂等**：同点同刻同值的原样重传自动跳过，不重复计数；
  同点同刻**不同值**（文件内或对比既有数据）→ 整批拒绝。
- **区间计量**：每个计量点按时刻连接相邻读数构成区间 `(t1, t2]`：
  - 区间内发生换表（`t1 < s <= t2`，**含后次读数时刻**）→ 标记缺口，不推算增量；
  - **未配置点**：增量 = 后次 − 前次，计入**后次读数所属 UTC 日**；增量为负（读数倒退）→ 整批拒绝；
  - **已配置点**：表盘读数须满足 `0 <= v < R`，否则读数越界、整批拒绝；
    设区间小时数为 `h`、归零次数为非负整数 `n`，折算增量
    `delta = v2 − v1 + n·R` 且 `0 <= delta <= P·h`（含两端，精确十进制计算）：
    - `n` 唯一 → 按后次读数所属 UTC 日计入用量；
    - 多个可行 `n` → 区间列为**待核**，不计入用量，网页与用量 API 单列待核区间及
      `n` 的取值范围（连同对应增量范围）；
    - 无任何可行 `n` → 区间**无解**，同样列入待核并拒绝引入该状态的写操作。
- **配置对历史和新读数都生效**：设置/修改配置时按提案参数全量复核该点历史明细，
  任一读数越界或区间无解即指出冲突并**拒绝本次配置变更，保留原配置、明细和版本号**。
- **补传只查受影响区间**：已配置计量点补传读数时，仅查询每个新读数前驱/后继所需的历史明细，
  不做全量扫描；补传读数或换表后自动重新判定受影响的区间（待核可转为已核算或缺口）。
- **晚到读数**插入后自动拆分旧区间，增量按新区间重新归属。
- **补录换表**后，原区间变为缺口，此前计入的增量自动撤销。
- **事务性**：一次上传/配置变更与其影响在同一事务内生效；任何校验失败整体回滚，
  保持旧数据；被拒批次/配置留有审计记录（首页最近批次可见，类型“归零配置”）。
- **并发一致性**：SQLite WAL 模式；所有写操作用 `BEGIN IMMEDIATE` 串行化，
  配置变更与上传交错时按一种先后顺序完整生效；查询在单个读事务内完成，
  每次查询返回的用量、待核区间与数据版本号必然对应同一组配置及明细（页面右上角显示版本号）。

## 运行

### Docker Compose（推荐）

```bash
docker compose up --build
```

访问 http://localhost:8000 。数据持久化在命名卷 `meter-data`（容器内 `/data/app.db`）。

### 本地开发

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
python run.py                 # 默认 0.0.0.0:8000（waitress）
pytest tests/                 # 运行测试
```

环境变量：`APP_DATABASE`（SQLite 路径，默认 `./data/app.db`）、`PORT`（默认 8000）、
`SECRET_KEY`、`USE_WAITRESS=0` 可退回 Flask 内置服务器。

## 页面与接口

- `GET /` — 上传入口、配置入口与当前配置、查询入口、最近批次（含被拒原因）。
- `GET/POST /config` — 表单设置/修改计量点的归零电量与最大功率（字段 `point`、`rollover`、`max_power`）。
- `POST /upload/readings`、`POST /upload/swaps` — 表单上传 CSV（字段名 `file`）。
- `GET /usage?point=..&start=..&end=..` — 逐日用量表 + 待核区间 + 缺口区间；日期缺省时取该点数据最近 31 天。
- `GET /api/usage?point=..&start=..&end=..` — 同口径 JSON（含数据版本号、当前配置 `config`、
  待核区间 `pending`：`resolution=pending|infeasible`、`n_min/n_max`、`min_kwh/max_kwh`），
  便于核对与集成。

## 实现说明

- 读数以文本存十进制（`Decimal` 计算，精度 40 位），时刻规范化为定宽 UTC 字符串（字典序即时间序）；
  区间小时数用整数微秒交叉相乘参与判定，避免浮点误差与除不尽导致的取整错误。
- 日用量不做冗余物化：查询时在单事务内由原始记录与当前配置现算，
  因此“配置、原始记录、受影响日结果”天然同事务/同版本生效，晚到读数/补录换表/改配置的影响即时可见。
- 代码结构：`app/logic.py`（解析、校验、归零换算、区间/日用量计算）、`app/routes.py`（页面与 API）、
  `app/db.py`（连接与建表）、`tests/`（原规则、归零规则与并发测试）。
